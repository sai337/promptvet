promptvet · open source (Apache-2.0)

Check a prompt before your team uses it

Paste any prompt or SKILL.md. promptvet flags jailbreaks, prompt injection, leaked secrets, risky advice personas and weak instructions, then scores it. It runs on simple rules, with no LLM call. Nothing you paste is stored.

For teams

Run promptvet as a CI gate on your prompt or skill repo (it outputs SARIF for code scanning), import only approved prompts into a self-hosted library, and build vetted SKILL.md packs. For help setting up a private, vetted prompt library, open an issue on GitHub.
